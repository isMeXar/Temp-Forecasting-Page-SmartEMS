# SmartEMS Forecasting Platform

Modern energy forecasting web application with React + Vite frontend and FastAPI backend (placeholder).

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

Visit: http://localhost:5173

## Project Structure

```
├── frontend/          # React + Vite + Tailwind CSS
├── backend/           # FastAPI (placeholder)
└── Models/            # Pre-trained ML models (.joblib)
```

## Features

- 4 energy sites with collapsible sections
- Multiple forecast horizons (1h to 1 month)
- Interactive charts with Recharts
- Real-time KPI metrics
- Mock data with realistic patterns
- Green professional theme

## Tech Stack

**Frontend**: React 19, Vite, Tailwind CSS, Recharts, Lucide Icons  
**Backend**: FastAPI (placeholder structure)  
**Models**: LightGBM, XGBoost with CEEMD features
